# 寝室扣分查看（DormScoreViewer）

ClassIsland 插件。从校园网「寝室内务」栏目抓取扣分公告，在主界面**逐条轮播**关注班级寝室的扣分，格式为「寝室号  扣分」（如 `2114  -1`）。

由 `dorm_score_viewer.py`（Python + Tkinter 单机版）移植而来，保留了原有的抓取与解析逻辑，并修复了其中一处失效的兜底逻辑。

## 功能

- **逐条轮播**：主界面一次只显示一条「寝室号  扣分」，每隔若干秒自动切换下一条，循环播放
- **可调字号**：字号可手动指定（如 14 小 / 18 中 / 24 大 / 32 特大），也可设为 0 由组件高度自适应
- **关注班级**：按班级筛选，一个班级下的所有寝室都会展示；未配置时自动回退显示全部
- **多日汇总**：可配置为汇总最近 N 天（1–60 天）的数据
- **离线可用**：抓取结果缓存在插件配置目录，断网时自动回退缓存并标注「来自缓存」
- **自动刷新**：按设定间隔自动拉取（0 为不自动刷新）
- **设置页面**：配置数据源、关注的班级、超时与刷新间隔，支持一键测试连接、清空缓存

## 环境要求

| 项目 | 版本 |
| --- | --- |
| ClassIsland | 2.x |
| ClassIsland.PluginSdk | 2.0.4（net8.0） |
| TargetFramework | net8.0-windows |
| .NET SDK | 8.0 或以上 |

> **为什么默认用 net8.0？** `net8.0` 编译出的程序集可以被 `net8.0` / `net9.0` / `net10.0` 的
> ClassIsland 2.x 运行时加载，是**兼容面最广**的选择。
> 反过来，用 `net10.0` 编译的插件**只能**被 `net10.0`（ClassIsland 2.1+）加载，
> 装到 `net8.0`（ClassIsland 2.0.x）上会**整个插件加载失败**——表现为主界面和设置页都找不到它。
>
> 如果你确定 ClassIsland 是 2.1+（.NET 10），想面向最新版，可把 `TargetFramework` 改为
> `net10.0-windows`、并把 `ClassIsland.PluginSdk` 改为 `2.1.1.1`。

## 构建与打包

### 一键脚本（推荐）

```powershell
# Windows PowerShell
.\build-cipx.ps1
```

```bash
# Linux / macOS
./build-cipx.sh
```

脚本会自动完成「还原 → 编译发布 → 打包」三步，产物输出到项目下的 `cipx/` 目录。
优先使用插件 SDK 的一键打包（`CreateCipx=true`，SDK 1.6.0.5+）；若当前 SDK 版本较旧，
会自动回退为手动压缩 `publish` 输出目录，两种方式产出的 `.cipx` 结构一致。

### 手动命令

```powershell
# 仅编译
dotnet build -c Release

# 一键打包（推荐），产物输出到项目下的 cipx 目录
dotnet publish -c Release -p:CreateCipx=true
```

> `.cipx` 本质上是 zip 压缩包，其中 `manifest.yml` 必须位于压缩包**根目录**。
> 手动打包时请压缩 `publish` 目录**内部的内容**，不要连带外层目录一起压。

## 安装

两种方式任选其一：

1. **从包安装**：在 ClassIsland 中打开【应用设置】→【插件】，安装上面生成的 `.cipx` 包。
2. **未打包加载**：把 publish 输出目录整体放到 ClassIsland 的插件目录下，重启应用。

安装后在【应用设置】→【组件】中把「寝室扣分」组件拖到主界面。

## 配置

打开【应用设置】→【寝室扣分】：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 站点根地址 | `http://10.132.11.5` | 结尾不要带斜杠 |
| 列表页路径 | `/news/?list_42.html` | 寝室内务栏目 |
| 详情页 URL 模板 | `/news/?{0}.html` | `{0}` 会被替换为文章 ID |
| 关注的班级 | 空 | 逗号/空格/分号分隔，如 `高一(1)班, 高三(2)班` |
| 请求超时 | 12 秒 | |
| 自动刷新间隔 | 30 分钟 | 0 表示不自动刷新 |

**班级名匹配会忽略空格与结尾的「班」字，并把全角括号转为半角**，所以 `高一(1)班`、`高一（1）`、` 高一 (1) ` 都会被识别为同一班级。
年级前缀（如「高一」）会保留参与匹配——若只填 `1班`，**不会**匹配到 `高一(1)`，这是有意为之，避免把高二/高三的同号班级一并命中。

组件自身的可选项在组件的设置界面里调整：

| 组件设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 汇总天数 | 1 | 1–60 天 |
| 轮播间隔 | 5 秒 | 0 表示不轮播、一次列出全部 |
| 字号 | 0（自动） | 像素值；常用 14 / 18 / 24 / 32 |
| 只显示关注班级的寝室 | 开 | 未配置班级时自动回退显示全部 |

## 适配其他学校

默认参数针对原脚本所用的平阳中学校园网（动易 CMS 风格，`list_42.html` 栏目）。换学校时：

1. 修改上述三个数据源配置项。
2. 若列表页链接格式不同，调整 `Services/DormScoreService.cs` 中的 `ArticleLinkRegex`。
3. 若表格列顺序不同，调整同文件中的 `ParseArticle`（目前约定：第 1 列班级、第 2 列寝室、第 3 列扣分、第 4 列原因）。

编码无需担心：页面可能是 GB2312 / GBK / UTF-8，插件会按「HTTP 头 → meta 声明 → 严格尝试候选编码 → 宽松兜底」的顺序自动识别。

## 实现说明

- 数据抓取与解析在后台线程完成，UI 更新切回 Avalonia UI 线程，不会卡住主界面。
- 单篇公告抓取失败不会中断整批任务，会自动回退到缓存并标注。
- 缓存文件为插件配置目录下的 `cache.json`，配置改动有 500ms 防抖合并写盘。
- 解析采用正则（与原始 Python 版一致），不引入额外 HTML 解析依赖。

### 与原 Python 脚本的一处重要差异

原脚本用 `re.findall(r"<t[dh][^>]*>(.*?)</t[dh]>", ...)` 取单元格，只拿到捕获组（单元格内部文本），
`<td x:num="...">` 的**属性被丢弃**，因此其中用于兜底读取 `x:num` 的代码从未生效——
遇到「数字只藏在 `x:num` 属性里」的公告（Excel 导出的页面常见）会整表漏解析。

本插件取单元格**完整匹配**（含标签与属性），`x:num` 兜底真正生效。
